Baixe a versão **Arduino IDE 2.x** (recomendado) ou **Arduino IDE 1.8.19**\n   - Windows: Arduino IDE Installer ou ZIP\n   - Mac: DMG installer\n   - Linux: AppImage ou via apt\n\n### Instalação no Windows\n\n```\n1. Execute o instalador (arduino-ide_*.exe)\n2. Escolha pasta de instalação (recomendado: C:\\Program Files\\Arduino IDE)\n3. Clique Next/Próximo em todas as telas\n4. Marque \"Instalar drivers USB\"\n5. Conclua a instalação\n6. Reinicie o computador (importante!)\n```\n\n### Verificação\n\nAbra o Arduino IDE. Você deve ver a tela principal com um exemplo vazio.\n\n---\n\n## 2. Instalação da Placa ESP32\n\n### Método 1: Via Arduino IDE (Recomendado)\n\n#### Passo 1: Adicionar URL da Placa\n\n1. Abra Arduino IDE\n2. Vá para **File → Preferences** (ou **Arduino → Preferences** no Mac)\n3. Na opção **Additional Board Manager URLs**, adicione:\n\n```\nhttps://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json\n```\n\n4. Clique **OK**\n\n#### Passo 2: Instalar Placa ESP32\n\n1. Vá para **Tools → Board → Boards Manager**\n2. Na caixa de busca, digite: `esp32`\n3. Procure por **\"esp32 by Espressif Systems\"**\n4. Clique nela e selecione a versão mais recente (ex: 2.0.11)\n5. Clique **Install**\n6. Aguarde ~2-3 minutos até completar\n7. Feche o Boards Manager\n\n### Método 2: Via Download Manual\n\nSe o método 1 não funcionar:\n\n1. Baixe: **https://github.com/espressif/arduino-esp32/releases**\n2. Procure por \"esp32-*.zip\" (ex: arduino-esp32-2.0.11.zip)\n3. Extraia em: `C:\\Users\\[SEU_USUARIO]\\AppData\\Local\\Arduino15\\packages\\esp32\\hardware\\esp32\\2.0.11`\n4. Reinicie Arduino IDE\n\n---\n\n## 3. Instalação de Bibliotecas Necessárias\n\nO código NexDose requer **6 bibliotecas**. Instale da seguinte forma:\n\n### Passo 1: Abrir Gerenciador de Bibliotecas\n\n1. **Sketch → Include Library → Manage Libraries**\n2. Ou pressione **Ctrl+Shift+I** (Windows/Linux) ou **Cmd+Shift+I** (Mac)\n\n### Passo 2: Instalar Cada Biblioteca\n\n#### 📦 Biblioteca 1: **PubSubClient** (MQTT)\n\n- Na caixa de busca, digite: `pubsubclient`\n- Procure: **PubSubClient by Nick O'Leary**\n- Versão: **2.8.0 ou mais recente**\n- Clique **Install**\n\n**Link direto:** https://github.com/knolleary/pubsubclient\n\n#### 📦 Biblioteca 2: **ArduinoJson**\n\n- Na caixa de busca, digite: `ArduinoJson`\n- Procure: **ArduinoJson by Benoît Blanchon**\n- Versão: **6.20.0 ou mais recente**\n- Clique **Install**\n\n**Link direto:** https://github.com/bblanchon/ArduinoJson\n\n#### 📦 Biblioteca 3: **ESP32Servo**\n\n- Na caixa de busca, digite: `ESP32Servo`\n- Procure: **ESP32Servo by John K. Bennett**\n- Versão: **0.13.0 ou mais recente**\n- Clique **Install**\n\n**Link direto:** https://github.com/jkb-git/ESP32Servo\n\n#### 📦 Biblioteca 4: **WiFi** (Incluída na placa ESP32)\n\n- Vem automaticamente com a instalação do ESP32\n- Não precisa ser instalada separadamente\n\n#### 📦 Biblioteca 5: **WebServer** (Incluída na placa ESP32)\n\n- Vem automaticamente com a instalação do ESP32\n- Não precisa ser instalada separadamente\n\n#### 📦 Biblioteca 6: **DNSServer** (Incluída na placa ESP32)\n\n- Vem automaticamente com a instalação do ESP32\n- Não precisa ser instalada separadamente\n\n#### 📦 Biblioteca 7: **EEPROM** (Incluída na placa ESP32)\n\n- Vem automaticamente com a instalação do ESP32\n- Não precisa ser instalada separadamente\n\n### Resumo de Instalação\n\n| Biblioteca | Status | Versão | Link |\n|------------|--------|--------|------|\n| WiFi | ✅ Incluída | - | Arduino |\n| WebServer | ✅ Incluída | - | Arduino |\n| DNSServer | ✅ Incluída | - | Arduino |\n| EEPROM | ✅ Incluída | - | Arduino |\n| PubSubClient | ⬇️ Instalar | 2.8.0+ | https://github.com/knolleary/pubsubclient |\n| ArduinoJson | ⬇️ Instalar | 6.20.0+ | https://github.com/bblanchon/ArduinoJson |\n| ESP32Servo | ⬇️ Instalar | 0.13.0+ | https://github.com/jkb-git/ESP32Servo |\n\n### Verificação de Instalação\n\nDepois de instalar as 3 bibliotecas:\n\n1. Vá para **Sketch → Include Library**\n2. Verifique se aparecem:\n   - PubSubClient\n   - ArduinoJson\n   - ESP32Servo\n\nSe aparecerem, está tudo certo! ✅\n\n---\n\n## 4. Configuração da Placa ESP32\n\n### Passo 1: Selecionar a Placa Correta\n\n1. Abra Arduino IDE\n2. Vá para **Tools → Board**\n3. Procure por **ESP32 Dev Module** ou apenas **ESP32** (depende da versão)\n4. Clique para selecionar\n\n**Obs:** Se não aparecer, a instalação da placa não funcionou. Refaça o passo 2.\n\n### Passo 2: Configurar Parâmetros\n\nVá para **Tools** e configure:\n\n```\nBoard:                ESP32 Dev Module\nUpload Speed:         921600 baud\nCPU Frequency:        240 MHz\nFlash Frequency:      80 MHz\nFlash Mode:           DIO\nFlash Size:           4MB (32Mb)\nPartition Scheme:     Default 4MB with spiffs\nCore Debug Level:     None\nErase All Flash:      Only Sketch\nPort:                 COM3 (ou outro disponível)\n```\n\n### Passo 3: Selecionar Porta COM\n\n1. Conecte a placa ESP32 ao PC via cabo USB\n2. Aguarde ~2 segundos\n3. Vá para **Tools → Port**\n4. Selecione a porta COM disponível (ex: COM3)\n\n**Se não aparecer nenhuma porta:**\n- Tente outro cabo USB\n- Instale drivers: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers\n- Reinicie Arduino IDE\n\n---\n\n## 5. Preparação do Código\n\n### Passo 1: Abrir o Código\n\n1. Abra Arduino IDE\n2. Vá para **File → Open**\n3. Navegue até: `C:\\Users\\[SEU_USUARIO]\\Documents\\NexDose\\IoT\\`\n4. Selecione: `NexDose_ESP32_WiFi_Provisioning.ino`\n5. Clique **Open**\n\nVocê deve ver o código carregado na janela principal.\n\n### Passo 2: Configurações Iniciais do Código\n\nAntes de fazer o upload, configure:\n\n#### Credenciais WiFi (Temporárias)\n\n**Localização:** Linhas 12-14\n\n```cpp\nString ssid = \"SSID_WIFI\";           // Será carregado da EEPROM depois\nString password = \"SENHA_WIFI\";       // Será carregado da EEPROM depois\n```\n\nPor enquanto, deixe como está. Clique no botão **✓ (Verificar)** na barra superior\n2. Aguarde a compilação\n3. Se aparecer **\"Compilação completa\"**, está tudo certo\n4. Upload do Programa\n\n### Passo 1: Conectar a Placa\n\n1. Conecte a placa ESP32 ao PC via cabo USB\n2. Verifique que a porta COM está selecionada (Tools → Port)\n3. Aguarde ~2 segundos até o LED da placa piscar\n\n### Passo 2: Fazer o Upload\n\n1. Clique no botão **→ (Upload)** na barra superior\n2. Aguarde a compilação e upload (~30-60 segundos)\n3. Você verá mensagens:\n   ```\n   Compiling sketch...\n   Uploading 276320 bytes...\n   ........\n   Upload complete!\n   ```\n\n### Passo 3: Verificar Upload\n\nQuando terminar:\n\n- ✅ Se ver **\"Upload complete\"** → Sucesso!\n- ❌ Se ver erro → Vá para seção **Troubleshooting**\n\n### Passo 4: Verificar Funcionamento\n\n1. O código iniciará automaticamente\n2. Vá para **Tools → Serial Monitor**\n3. Configure velocidade em **115200 baud** (canto inferior direito)\n4. Você deve ver mensagens de inicialização\n\n**Esperado:**\n```\n========== NexDose ESP32 INICIANDO ==========\n\n✓ Credenciais carregadas: SSID=...\nTentando conectar ao WiFi: SSID_WIFI\n```\n\n---\n\n## 7. Testes e Validação\n\n### Teste 1: Verificar Inicialização\n\n1. Abra **Serial Monitor** (Tools → Serial Monitor)\n2. Configure **115200 baud**\n3. Resete a placa (botão RESET)\n4. Troubleshooting\n\n### Problema 1: \"Port COM não aparece\"\n\n**Causa:** Driver USB não instalado\n\n**Solução:**\n```\n1. Baixe driver: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers\n2. Instale conforme seu OS\n3. Reinicie o computador\n4. Reconecte a placa ESP32\n```\n\n### Problema 2: \"Upload timeout ou falha\"\n\n**Causa:** Conexão USB instável ou velocidade incorreta\n\n**Solução:**\n```\n1. Clique Tools → Upload Speed → 115200\n2. Pressione BOOT + RST simultaneamente\n3. Tente upload novamente\n4. Se persistir, tente cabo USB diferente\n```\n\n### Problema 3: \"Erro de compilação: undefined reference\"\n\n**Causa:** Biblioteca não instalada corretamente\n\n**Solução:**\n```\n1. Vá para Tools → Manage Libraries\n2. Procure pela biblioteca que está faltando\n3. Clique em Uninstall (se existir)\n4. Aguarde 10 segundos\n5. Clique em Install novamente\n6. Reinicie Arduino IDE\n```\n\n### Problema 4: \"Servo não se move\"\n\n**Causa:** Pino GPIO incorreto ou servo desconectado\n\n**Solução:**\n```\n1. Verifique conexões físicas dos servos\n2. Confirme pinos em:  Linhas 29-31\n   const int SERVO1_PIN = 32;  // GPIO32\n   const int SERVO2_PIN = 33;  // GPIO33\n   const int SERVO3_PIN = 25;  // GPIO25\n3. Se mudar pinos, salve e faça upload novamente\n```\n\n### Problema 5: \"Serial Monitor vazio ou não conecta\"\n\n**Causa:** Velocidade de baud incorreta\n\n**Solução:**\n```\n1. No Serial Monitor, canto inferior direito\n2. Selecione: 115200 baud\n3. Clique Reset na placa\n4. Você deve ver mensagens\n```\n\n### Problema 6: \"WiFi provisioning não funciona\"\n\n**Causa:** DNS ou servidor web com problema\n\n**Solução:**\n```\n1. Tente conectar via IP direto: http://192.168.4.1\n2. Use navegador desktop (não celular)\n3. Reinicie a placa (botão RESET)\n4. Tente novamente em AP Mode\n```\n\n---\n\n## 📋 Checklist Final\n\n### Antes de Usar\n\n- [ ] Arduino IDE 2.x instalado\n- [ ] Placa ESP32 instalada em Arduino IDE\n- [ ] 3 bibliotecas instaladas (PubSubClient, ArduinoJson, ESP32Servo)\n- [ ] Código carregado em: `NexDose_ESP32_WiFi_Provisioning.ino`\n- [ ] Upload completo e sem erros\n- [ ] Serial Monitor funcionando (115200 baud)\n- [ ] Servo motors respondendo a comandos\n- [ ] Sistema iniciando corretamente\n\n### Funcionamento Esperado\n\n- [ ] Medicações agendadas via MQTT\n- [ ] Servo motors acionados em sequência (1 por vez)\n- [ ] Nunca 2 servos movem simultaneamente\n- [ ] LED WiFi acende quando conectado\n- [ ] LED Medicação acende quando dose dispensada\n- [ ] Buzzer toca em eventos importantes\n- [ ] Gaveta com sensor ultrassônico funciona\n\n---\n\n## 🔗 Links Úteis\n\n| Recurso | Link |\n|---------|------|\n| Arduino IDE | https://www.arduino.cc/en/software |\n| GitHub ESP32 | https://github.com/espressif/arduino-esp32 |\n| PubSubClient | https://github.com/knolleary/pubsubclient |\n| ArduinoJson | https://github.com/bblanchon/ArduinoJson |\n| ESP32Servo | https://github.com/jkb-git/ESP32Servo |\n| Driver USB | https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers |\n| Documentação ESP32 | https://docs.espressif.com/projects/esp-idf/en/latest/esp32/ |\n\n---\n\n## ✅ Status\n\nAo completar todos os passos deste guia, você terá:\n\n✅ IDE Arduino funcionando\n✅ Placa ESP32 reconhecida\n✅ Todas as bibliotecas instaladas\n✅ Código carregado e testado\n✅ Sistema NexDose operacional\n✅ Servo motors em sequência garantida\n✅ Pronto para uso em produção\n\n---\n\n**Versão:** 1.0\n**Data:** 2 de Junho, 2026\n**Status:** ✅ Pronto para Implementação\n\n**Dúvidas?** Consulte a seção Troubleshooting ou acesse os links de documentação oficial das bibliotecas.\n
